# Aya Abdallah — Cloud & DevOps Portfolio

A responsive, single-page portfolio built with React + Vite. The layout takes inspiration from a terminal-style DevOps portfolio, with a strong focus on Cloud & DevOps skills and experience.

## Sections
- Home / terminal-style introduction
- About
- Cloud & DevOps toolkit
- Experience
- Education and training
- Research, publications and achievements
- Contact

There is intentionally **no projects section**, per request.

## Run locally
```bash
npm install
npm run dev
```

## Customize
- `src/config.js`: profile text, contact links, skills, education, experience, credentials, publications and achievements.
- `src/App.jsx`: page structure and section order.
- `src/styles.css`: visual styling and responsive layout.

## Deploy to GitHub Pages
```bash
npm install
npm run deploy
```
